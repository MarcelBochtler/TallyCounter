# Tally Counter privacy policy redirect

This repository preserves the legacy privacy-policy URL:

https://marcelbochtler.github.io/TallyCounter/

`index.html` redirects browsers to the current policy at:

https://marcelbochtler.github.io/privacy-policy/

The page uses an immediate HTML refresh and provides a clickable fallback link.
GitHub Pages publishes directly from the root of `main`; `.nojekyll` disables
Jekyll processing. No custom build workflow is required for this static redirect.

Keep this redirect available for existing app versions and store listings.
Maintain the policy and its Markdown-to-HTML workflow in the `privacy-policy`
repository, not here.
